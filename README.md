# 🌿 WildGuard – Wildlife & Nature Conservation Website

> **One planet. Countless lives.** A modern, responsive web application built to spread awareness about wildlife protection, endangered species, and ecosystem preservation.

---

## ✨ Features

* **Interactive Navigation:** Smooth-scrolling links for seamless user experience across different sections.
* **Stunning Hero Section:** High-impact nature background with clear typography and quick call-to-action buttons.
* **Educational Wildlife Cards:** Detailed spotlights on endangered species (Bengal Tigers, Elephants, and Sea Turtles) with conservation status badges.
* **Actionable Sustainability Grid:** Practical tips for users to reduce waste, plant native species, and respect wildlife.
* **Integrated Feedback & Registration Form:** A dynamic JavaScript-powered form that instantly captures visitor details (Name, Feedback/Age, and Email) and renders confirmation details directly on the page.
* **Fully Responsive Design:** Optimized layouts that adapt smoothly to mobile phones, tablets, and large desktop screens.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure (`<header>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Custom styles, CSS Grid, Flexbox, media queries for responsiveness, and smooth transitions.
* **JavaScript (ES6):** Client-side form handling and event listeners for dynamic feedback updates.
* **Unsplash Assets:** High-resolution nature and wildlife photography.
